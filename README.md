# Diario Íntimo — releases públicas

Este repositorio contiene únicamente los instaladores oficiales y los metadatos de actualización de Diario Íntimo para Windows y Android.

- El código fuente permanece en el repositorio privado `lousoparaelmac6-code/diario-intimo`.
- Windows usa releases con prefijo `desktop-` e incluye el instalador y los metadatos que necesita el actualizador.
- Android usa releases con prefijo `apk-` e incluye el APK y el manifiesto público de actualización.
- No se deben subir contraseñas, tokens, claves privadas, archivos `.env` ni datos personales.
